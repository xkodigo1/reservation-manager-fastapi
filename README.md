# Reservation Manager API

REST API for managing coworking rooms and reservations across two headquarters (Bogotá and Medellín). Built with **FastAPI**, **SQLAlchemy** and **MySQL**, with JWT authentication and role-based access for regular users and administrators.

## Features

- **Authentication**: register and log in with email and password; passwords hashed with bcrypt; stateless JWT access tokens (HS256, configurable expiration).
- **Roles**: `user` and `admin`. Admin-only endpoints are guarded by a `require_admin` dependency.
- **Rooms**: public listing; create, update and delete restricted to admins. Each room belongs to a headquarter (`Bogotá` or `Medellín`).
- **Reservations**: users create and cancel their own reservations; admins can act on any. Reservations move through `pending`, `confirmed` and `canceled`, and cancelling is a soft status change, not a delete.
- **Interactive docs**: Swagger UI at `/docs` and ReDoc at `/redoc`, generated by FastAPI.
- **Migrations**: database schema managed with Alembic; a plain SQL schema and seed data are also included.

## Endpoints

| Method | Path | Access | Description |
| --- | --- | --- | --- |
| POST | `/auth/register` | Public | Create an account and receive a token |
| POST | `/auth/login` | Public | OAuth2 password form login, returns a token |
| GET | `/users/me` | Authenticated | Current user profile |
| GET | `/users/` | Admin | List users |
| DELETE | `/users/{user_id}` | Admin | Delete a user |
| GET | `/rooms/` | Public | List rooms |
| POST | `/rooms/` | Admin | Create a room |
| PUT | `/rooms/{room_id}` | Admin | Update a room |
| DELETE | `/rooms/{room_id}` | Admin | Delete a room |
| POST | `/reservations/` | Authenticated | Create a reservation (own, or any if admin) |
| GET | `/reservations/me` | Authenticated | Current user's reservations |
| GET | `/reservations/room/{room_id}` | Public | Reservations for a room |
| GET | `/reservations/date/{reservation_date}` | Public | Reservations on a date (`YYYY-MM-DD`) |
| DELETE | `/reservations/{reservation_id}` | Owner or admin | Cancel a reservation |

## Project structure

```text

├── main.py                  # FastAPI app and router registration
└── app/
    ├── api/
    │   ├── deps.py          # get_current_user (JWT → user)
    │   └── routes/          # auth, users, rooms, reservations
    ├── core/                # settings, JWT helpers, password hashing
    ├── db/                  # engine/session, base, SQL schema and seeds
    ├── models/              # SQLAlchemy models
    ├── schemas/             # Pydantic request/response models
    └── utils/               # get_db dependency
alembic/                     # migrations
```

## Getting started

### Requirements

- Python 3.10+
- MySQL 8

### Setup

```bash
git clone https://github.com/xkodigo1/reservation-manager-fastapi.git
cd reservation-manager-fastapi
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install fastapi uvicorn sqlalchemy pymysql alembic pydantic-settings \
  python-dotenv python-multipart "pydantic[email]" "passlib[bcrypt]" "python-jose[cryptography]"
```

Create `backend/.env` with your own values:

```env
db_host=localhost
db_port=3306
db_user=your_user
db_password=your_password
db_name=reservation_manager

jwt_secret_key=change-me
jwt_algorithm=HS256
jwt_expiration_seconds=3600
```

Create the database schema, either with Alembic or with the SQL files in `backend/app/db/`:

```bash
mysql -u your_user -p reservation_manager < backend/app/db/schema/structure.sql
mysql -u your_user -p reservation_manager < backend/app/db/seeds/initialData.sql
```

Run the API:

```bash
cd backend
uvicorn main:app --reload
```

Then open <http://localhost:8000/docs>.
